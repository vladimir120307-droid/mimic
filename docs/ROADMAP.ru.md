# Дорожная карта

С версиями, с мнением, намеренно короткая. Делаем по одной вещи за раз.

## v0.1 — Скриншот → Flutter (цель: этот месяц)

Минимальный MVP, который доказывает тезис.

- [x] Скелет проекта
- [ ] `mimic gen IMAGE --target flutter` работает end-to-end
- [ ] Адаптер Claude Vision со structured-output промптингом
- [ ] Flutter-генератор: выдаёт компилируемый `main.dart` для ~10 эталонных входов
- [ ] Базовая CLI с подкомандой `gen`
- [ ] Первый демо-GIF для README

**Готово когда:** кидаешь скриншот любого разумного мобильного UI, получаешь Flutter-файл, который компилируется и рендерит что-то визуально похожее (структурное совпадение 90%+).

## v0.2 — Видео и мульти-таргет (цель: +6 недель)

Добавляет настоящий дифференциатор и расширяет охват.

- [ ] Нативный захват экрана (сначала Windows DXGI, затем macOS, затем Linux)
- [ ] Дедуп кадров в C++ (порог перцептивного хэша)
- [ ] Распознавание click-flow — несколько состояний склеиваются в одно Flutter-приложение
- [ ] Генератор HTML + Tailwind
- [ ] Генератор React + Tailwind
- [ ] CLI-подкоманда `mimic record`

**Готово когда:** 15-секундная запись мульти-экранного флоу выдаёт Flutter-приложение с навигацией между экранами.

## v0.3 — Десктоп UI на Flutter (цель: +10 недель)

Делаем доступным для не-CLI пользователей.

- [ ] Flutter-приложение: выбор области, record/stop, панель preview
- [ ] Live preview — сгенерированный UI отрисовывается по мере выдачи кода
- [ ] Inline-редактор исходника с подсветкой
- [ ] Просмотр библиотеки прошлых записей
- [ ] Установщик для Windows / macOS / Linux

**Готово когда:** разработчик может установить, нажать запись и экспортировать рабочий Flutter-файл не трогая терминал.

## v0.4 — Локальная модель (цель: +14 недель)

История про приватность и стоимость.

- [ ] Адаптер Florence-2 (CPU + CUDA)
- [ ] Адаптер Llava через Ollama
- [ ] Регрессионный набор по качеству — известно-хорошие выходы для каждого входа, % структурного совпадения по провайдерам
- [ ] Переключаемо CLI-флагом и переключателем в UI

**Готово когда:** весь пайплайн работает без сети; качество в пределах 80% от Claude на регрессионном наборе.

## v1.0 — Знание библиотек (цель: до конца года)

Полировка, которая отделяет популярный инструмент от дефолтного.

- [ ] Распознавание Material 3 компонентов для Flutter-таргета
- [ ] Распознавание shadcn/ui компонентов для React-таргета
- [ ] Дедуп Tailwind-классов / извлечение темы
- [ ] Переиспользование компонентов — повторяющиеся UI-элементы выдаются как общие виджеты
- [ ] Plugin API для community-таргетов (SwiftUI, Compose, Vue)

**Готово когда:** сгенерированный код читается как написанный Flutter-разработчиком, а не роботом.

## Вне scope (пока)

- Запись на мобилке (Android/iOS как источник записи)
- Версия как браузерное расширение
- Hosted / SaaS-версия
- Аудио/голосовая аннотация записей

Может быть позже. Явно не блокирует v1.0.

## Как решается приоритет

1. Открывает ли это use case, который двигает stars / installs?
2. Хуже ли нас альтернативный инструмент в этом?
3. Можем ли мы зашипить это меньше чем за 4 недели работы?

Если да на все три — идёт ближе к верху. Иначе ждёт.
