# Assets

- `logo.svg` — project logo (placeholder, to be refined).
- `demo.gif` — hero demo for the README. **Required before public launch.**

## Producing the demo GIF

The README hinges on this. Aim for:

- 6–10 seconds
- Top half: a familiar UI being recorded (e.g. Twitter / a banking app)
- Bottom half: generated Flutter code typing in real time
- Final frame: side-by-side preview vs. original

Tooling: ffmpeg + gifski for size, OBS for capture. Target ≤ 5 MB.
