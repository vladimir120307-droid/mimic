# mimic-cli

Python package for the [mimic](https://github.com/Cyber-Lord/mimic) project — screen recordings and screenshots into working Flutter / HTML / React code.

```bash
pip install mimic-cli

mimic gen screenshot.png --target flutter --out lib/
mimic record --duration 15 --target flutter --out lib/
```

See the [main README](../README.md) for full project documentation.
